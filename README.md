# MiniInfra

《超轻量 AI Infra 入门教程》的配套代码。用可运行的小实验拆开大模型训练、推理和 Agent 工具执行背后的基础设施。

## 选一篇开始

### [基础知识篇](base/README.md)

如果还读不顺推理或训练源码，可以从这里补齐前置知识。从浮点数和张量形状开始，逐步搭出 Transformer Block，再理解生成、显存和分布式通信。55 节各有一个小实验，大部分可以在 CPU 上跑，方便把公式、张量形状和实际输出对起来。

### [推理篇](inference/README.md)

一次模型请求如何变成一串 Token？从手写 Qwen3-0.6B 的分词和自回归生成出发，逐章加入 KV Cache、连续批处理和调度，最后把 Prefill 和 Decode 分到不同进程。沿着同一个模型，可以观察每项优化怎样影响延迟、吞吐和显存。

### [训练篇](training/README.md)

从单卡手写 Qwen3-0.6B 全参数 SFT 开始，依次实现数据流水线、混合精度、DDP、ZeRO 和模型并行，最后做到双节点混合并行与断点恢复。适合已经能跑通训练、想进一步搞清参数、梯度和优化器状态放在哪张卡上、何时通信的读者。

### [算子篇](kernel/README.md)

当瓶颈落在一个算子上，这一篇带你下到 GPU Kernel。实验从 RMSNorm、融合和访存布局讲到 GEMM、Attention、量化和 MoE。先用 CPU 参考实现核对结果，再按实验支持的平台比较 CUDA 与 MUSA，找出时间花在访存、计算还是启动上。

### [沙箱篇](sandbox/README.md)

面向需要为 Agent 搭建工具执行环境的开发者。从一个可以创建会话、执行命令、取回结果的最小服务出发，逐步处理进程取消、资源配额、文件产物、网络出站和调度。主线可以在 Linux 和 Docker 上动手，后续还能比较容器和 microVM，并把沙箱接进在线 Agent 或训练 rollout。

## 仓库范围

本仓库收录实验源码、运行脚本、依赖配置和运行所需的小型固定输入。书稿、PDF、实验报告、权重和生成产物保存在原工程或本地。
